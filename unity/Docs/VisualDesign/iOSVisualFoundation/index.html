Four realms become four kingdoms.

The first management view now shares one trustworthy building quote flow while each realm changes its construction silhouette, road logic, and spatial rhythm—not merely its color.

  • Brand first. Approved project marks remain exact, not regenerated.
  • iOS aware. Safe-area padding, 44-point controls, readable type, and reduced motion.
  • Realm structure. Shape, name, motif, and state carry identity—not color alone.
  • Trust before spend. Selecting a building only reveals its authoritative quote; a separate action authorizes construction.
