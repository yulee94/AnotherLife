## Authority and use

The Hermes Kanban remains the durable authority. This file is a versioned,
human-readable register of Gate 0 source constraints; it does not replace or
weaken the cited cards or comments. Downstream work must read the cited source
before implementing a requirement.

Apply sources in this order:

1. `t_93c953eb`, comment `863`, **CONTROLLING SUPERSESSION INDEX**.
2. The newest explicit owner ruling or owner approval on the cited decision card.
3. A completed `DECISION LOCKED` card body.
4. Supporting repository direction only where a board source expressly adopts it,
   such as `DESIGN.md` through `t_001b58cf`.

A conflict, missing source, unavailable evidence, or ambiguity is not permission
to choose a default. Stop the affected work, preserve the last approved baseline,
log the issue in the unresolved ledger, and return it to the named owner authority.
No agent, vendor, platform default, benchmark, calendar, aggregate metric, or
technical pass may exercise an owner-reserved decision.

Status terms used below:

- **IMMUTABLE — LOCKED:** binding until its cited reopen trigger is satisfied and
  the authorized decision maker records a replacement ruling.
- **IMMUTABLE — APPROVED PROVISIONAL:** binding as approved, but its source defines
  an evidence-and-owner process for recalibration.
- **IMMUTABLE — DEFERRED / FAIL CLOSED:** the deferral is binding; there is no
  implementation or release default.
- **IMMUTABLE — HISTORICAL SUPERSEDED:** retained for audit only and never consumed
  as current authority.
